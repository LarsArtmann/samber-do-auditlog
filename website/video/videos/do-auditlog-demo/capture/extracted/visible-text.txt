[h2] Everything you need to audit your DI container.
[p] Drop-in observability with zero ceremony.
[h3] Drop-in Setup
[p] One line: do.NewWithOpts(plugin.Opts()). Zero config, zero ceremony.
[h3] Dependency Graph
[p] Infers which service resolved which — forward and reverse — without touching do's internals.
[h3] Scope Tree
[p] Full hierarchy with per-scope service lists, cross-scope resolution tracked automatically.
[h3] 16+ Export Formats
[p] JSON, NDJSON, CSV, TSV, HTML, Mermaid, PlantUML, DOT, D2, tree, and table.
[h3] Health Check Audit
[p] Wraps injector.HealthCheck() with per-service events and unhealthy-service detection.
[h3] ~1.7us Overhead
[p] In-memory capture during operation. Toggle off for zero cost. Export only when you need it.

[h2] How it works.
[p] Three steps from zero to full observability.
[h3] Create the Plugin
[p] Pass plugin.Opts() to do.NewWithOpts. Hooks fire on every registration, invocation, and shutdown.
[h3] Run Your Container
[p] The plugin captures events in memory with an invocation stack that infers the dependency graph.
[h3] Export & Visualize
[p] Get a JSON snapshot, NDJSON event stream, or a self-contained HTML page. Or render Mermaid, DOT, D2, PlantUML.
