## e) WHAT WE SHOULD IMPROVE 🔧

### Process (this session's lessons)

1. **Commit discipline > documentation.** Writing "commit yourself" in CONTRIBUTING.md while letting the daemon commit is worse than not writing it — it's hypocrisy. The fix is behavioral: commit after each logical unit, before starting the next task.
2. **The auto-git daemon is an active hazard during remediation sessions.** It converts careful, descriptive-change-intent work into generic `chore(...)` noise. Consider pausing it or committing preemptively.
3. **PIPESTATUS in background shells is unreliable.** The `>/tmp/out 2>&1; ec=$?` pattern (which I used for lint) is the only trustworthy form. Adopt it everywhere, including for test runs.
